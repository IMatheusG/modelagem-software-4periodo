Título: ADR 0001 — Decisão da linguagem Node.js para a API dos Sensores e Atuadores
Status: Aprovado
Contexto: Sistema apresentava alta latência na resposta, quando se tem muitos atuadores e sensores integrados.
Decisão: Foi adotado o Node.Js, pois permite realizar múltiplas tarefas sem travar a thread em uma única tarefa demorada.
Consequências: Vantagens são, menor latência e maior confiabilidade do servidor. Os pontos negativos seriam, ter que reescrever código legado e uma dificuldade em configurações e no primeiro deploy do servidor.
